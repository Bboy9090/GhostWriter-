# Bobby's Word Bench — Brand Transition

## Public product name
**Bobby's Word Bench**

Internal storage keys, existing backup compatibility, repository paths, deployment wiring, and API contracts remain stable during the public-name transition.

## Product promise
A private, local-first writing and publishing workspace for drafting, revising, organizing, AI-assisted editing, and export.

## Icon master
- Primary symbol: a clean document sheet seated on a compact workbench/base.
- A pen-nib/cursor intersection forms the active creation point.
- Do not use a ghost mascot; the new brand should read as writing software immediately.
- Mark must remain readable at 32 px and work in monochrome.

## Splash master
- Rough notes enter from the left side of a minimal bench.
- A polished manuscript/page leaves the right.
- Center wordmark: **Bobby's Word Bench**.
- Secondary line: **Draft it. Shape it. Finish it.**

## Required production exports
- 1024×1024 store/PWA master.
- 512 and 192 PWA icons.
- 180 Apple touch icon.
- 64 and 32 favicon.
- 2732×2732 splash/launch-art master.
- Transparent SVG source mark.

## Compatibility rule
Do not rename localStorage keys beginning with `ghostwriter:`, existing project schemas, backup schema identifiers, repo URLs, or backend contracts until a separately tested data-migration release exists.
